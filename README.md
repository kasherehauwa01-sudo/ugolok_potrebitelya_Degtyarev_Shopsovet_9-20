# Уголок потребителя — ШопСовет

Статическая адаптивная страница для ИП Дегтярева Алексея Игоревича. Сборка и установка зависимостей не нужны.

## Локальный запуск

Из каталога репозитория:

```sh
python3 -m http.server 8000 --bind 0.0.0.0
```

Открыть страницу на порту 8000. Для размещения достаточно любого статического хостинга. Кнопка «Распечатать» использует диалог печати браузера.

## Источники

Реквизиты и контакты взяты из предоставленной карты партнёра, режим работы — из фотографии стенда. Фактический адрес указан как в карте партнёра; отдельный адрес торговой точки не предоставлен. Телефон защиты прав потребителей перенесён со стенда и требует подтверждения актуальности. Экстренные номера: 101–104, 112.

Правовые ссылки ведут на Закон РФ от 07.02.1992 № 2300-1 и постановление Правительства РФ от 31.12.2020 № 2463 в КонсультантПлюс. В documents/egrip.pdf размещён предоставленный лист записи ЕГРИП.

ШопСовет оформлен текстовым знаком; исходный графический логотип не включён в файлы проекта. Шрифт Manrope загружается из Google Fonts, при отсутствии сети используется Arial.
